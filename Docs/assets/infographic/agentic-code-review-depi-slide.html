Agentic Code Review

Review that shows its evidence.
A local command-line reviewer for TypeScript and JavaScript changes. It resolves the change set, runs the project’s own tests and type-check, and passes that evidence to a single schema-validated model pass — findings in the terminal, as JSON and as a self-contained HTML page.

Project roadmap
01

The problem

  • AI writes code faster than a team can read it
  • Clean code, passing tests, no signal
  • Reviews take about five times as long
  • Nearly a third more changes skip review
02

The solution

  • One local CLI, no server and no account
  • Every finding cites evidence or says unverified
  • A review under every failure mode
  • Nothing fails silently
03

Who it serves

  • The reviewer of a teammate’s pull request
  • The author, before they push
  • The tech lead guarding the design
  • Maintainers measuring the engine
04

Core features

  • Five change scopes, including a public PR by URL
  • The project’s own tests and type-check as evidence
  • Related source context at depth 0–1
  • Terminal, JSON and HTML output
05

Architecture

  • A fixed, acyclic graph our code owns
  • Nine core functions, CF-1 to CF-9
  • One core behind thin adapters
  • Eight import contracts hold the seams
06

The AI layer

  • One isolated review pass, no shared history
  • Findings enter only through emit_finding
  • Schema-checked at the call boundary
  • One repair turn, then it stops
07

Measurement

  • A curated corpus of known defects
  • A catch rate and a false-positive figure
  • A pattern rule library, yours or ours
  • Every later change judged, not argued
